# 跨电脑复测指南

## 适用范围

本文定义 V9 公共评测的可复现运行顺序。V2 的 `tts-bench/config/neutral-evaluation-v2.json`、`tts-bench/config/evaluation-assets-v2.json` 与 `tts-bench/scripts/run_neutral_evaluation_v2.py` 仍是历史 V2 流程的权威入口；V9 不得借用其已排除的长音频指标。

V9 的输入事实源为 `tts-bench/config/neutral-evaluation-v9.json`：`longAudioTestV9/ai_deal.json` 中 77 段实际台词串用于全文 CER，`text.md` 仅作原文核对，不能替代 CER 参考文本。

## 环境与离线资源

长音频 CER 使用 `seed_tts_eval`。不要使用 `audio_eval` 代替它；该环境名称是历史名称，V9 公共评测不会加载 Seed-TTS-Eval、Paraformer 或 WavLM。

在本机 shell 中设置以下变量；它们不能写入仓库配置或 `.env`：

```bash
export HF_MIRROR_ROOT="$HOME/hf-mirror"
export HF_HUB_OFFLINE=1
export TRANSFORMERS_OFFLINE=1
export SEED_TTS_SENSEVOICE_DIR="$HOME/hf-mirror/FunAudioLLM/SenseVoiceSmall"
export SEED_TTS_TURBO_DIR="$HOME/hf-mirror/openai/whisper-large-v3-turbo"
```

正式评分前，先运行 `python -m pip check`，并确认 `seed_tts_eval` 能导入 torch、torchaudio、funasr、transformers、soundfile、scipy、jiwer、zhconv 与 zhon。

## V9 长音频受限评测

V9 仅允许以下长音频观测：音频交付原始测量、SenseVoice CER（字符错误率）和 Whisper-large-v3-turbo CER。两个 CER 独立报告和排名；不得运行长音频 WavLM SIM、SpeechBrain ECAPA SIM、UTMOSv2、NISQA，也不得生成自动综合分。

预检会验证输入哈希、ASR 模型 revision、模型哈希、CUDA 与 7 模型 × 5 角色的 V9 输入集合：

```bash
conda run --no-capture-output -n seed_tts_eval \
  python tts-bench/scripts/check_neutral_evaluation_v9_setup.py --strict-versions
```

每次正式评分必须使用一个新的、尚不存在的目录；只允许对同一次中断使用 `--resume`。一次进程只传入一个模型：

```bash
conda run --no-capture-output -n seed_tts_eval \
  python tts-bench/scripts/run_neutral_evaluation_v9.py \
  --model-id dots.tts-base \
  --output-dir longAudioTestV9/评测结果/task10-v9-YYYYMMDDTHHMMSSZ \
  --strict
```

其余六个模型复用同一 `--output-dir` 并增加 `--resume`。全部覆盖后生成：

```bash
python tts-bench/scripts/generate_neutral_v9_reports.py \
  --results-dir longAudioTestV9/评测结果/task10-v9-YYYYMMDDTHHMMSSZ \
  --reports-dir longAudioTestV9/评测结果
```

输出为双 CER 报告与音频交付与文本一致性报告。若发布渠道格式/响度阈值、强制对齐或角色分类器未冻结，报告只能给出原始测量值或“未执行”，不得擅自判定通过、失败或优劣。

## 独立 Seed-TTS 基准

Seed-TTS-Eval 不属于本 V9 长音频复测。请另按 [Seed-TTS评测任务.md](../Seed-TTS评测任务.md) 执行；相同冻结模型版本只运行一次，不因 task8/task9 重复评分。
